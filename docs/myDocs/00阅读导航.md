本目录是 `cpp-http-server` 的源码学习笔记，按主题拆分，适合一边阅读文档、一边定位实现。

- 分析基线：提交 `2733afe`，整理日期为 2026-10-07。
- 分析方式：阅读源代码、CMake 配置和测试代码。按本次要求，不编译、不启动服务器、不执行测试。
- “当前行为”指从实现直接推导的行为；“预期结果”指待运行验证的判断，不代表实测通过。
- 代码链接使用相对路径；行号锚点对应上述基线，后续修改后请优先按函数名定位。

## 建议怎么读

第一次读按 `01 → 02 → 03 → 05 → 14` 建立全局认识，再按兴趣进入 06～12。跟踪一个请求时，先选择 `GET /about`；理解静态响应后，再跟踪 `POST /api/users`。

有三点应一直区分：TCP 连接不等于单个 HTTP 请求；提交 JSON 用户数据不等于上传文件；源码存在测试不等于本次已经运行通过。

原始说明可对照 [README](../../README.md) 和 [ARCHITECTURE](../ARCHITECTURE.md)，但具体行为以实现为准。原说明中的“严格单向分层”“约 250 ms 退出”“符号链接防护已有测试”等表述均需结合 03、12、13、15 中的限定理解。
