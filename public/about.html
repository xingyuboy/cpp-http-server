This page is served by the static file handler. The socket handling, HTTP parsing, routing, thread pool and JSON encoding are all implemented in this project rather than pulled from a framework.

It is a learning and portfolio project. It is not hardened for internet-facing use: there is no TLS, no chunked transfer encoding and no request rate limiting.

Try the JSON endpoints: /api/users, /api/health, /api/benchmark.
